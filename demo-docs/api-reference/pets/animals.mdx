## List all animals

> Returns a paginated list of all animals in the store. Use `limit` to control page size and `status` to filter by availability.

**GET** `/pets`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true}>
  Pass your API key as a Bearer token in the `Authorization` header.
</ParamField>

<ParamField query="limit" param-type="integer">
  Maximum number of animals to return. Defaults to 20, max 100.
</ParamField>

<ParamField query="status" param-type="string" enum="available,pending,sold">
  Filter by availability status.
</ParamField>

**Responses**

`200` A paginated list of animals.

<ResponseField name="name" field-type="string" required={true}>
  The animal's name.
</ResponseField>

<ResponseField name="categoryId" field-type="integer" required={true}>
  The ID of the category this animal belongs to.
</ResponseField>

<ResponseField name="status" field-type="string" enum="available,pending,sold" />

<ResponseField name="id" field-type="integer" required={true}>
  Unique identifier assigned on creation.
</ResponseField>

`401` Missing or invalid API key.

<ResponseField name="code" field-type="string" required={true}>
  A machine-readable error code.
</ResponseField>

<ResponseField name="message" field-type="string" required={true}>
  A human-readable description of the error.
</ResponseField>

<ResponseField name="status" field-type="integer" required={true}>
  The HTTP status code.
</ResponseField>

</ParamField>

**Request body**
