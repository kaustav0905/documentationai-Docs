## List orders

> Returns all orders placed in the store. Does not currently support filtering or pagination.
> 
> <Callout kind="info">
>   Filtering and pagination are planned for v2. Subscribe to the [changelog](https://petstore.example.com/changelog) for updates.
> </Callout>

**GET** `/store/orders`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true}>
  Pass your API key as a Bearer token in the `Authorization` header.
</ParamField>

**Responses**

`200` An array of orders.

<ResponseField name="id" field-type="integer">
  Unique order identifier.
</ResponseField>

<ResponseField name="petId" field-type="integer">
  The ID of the animal in this order.
</ResponseField>

<ResponseField name="quantity" field-type="integer">
  Number of units ordered.
</ResponseField>

<ResponseField name="shipDate" field-type="string">
  Expected or actual ship date in ISO 8601 format.
</ResponseField>

<ResponseField name="complete" field-type="boolean">
  Whether the order has been fulfilled.
</ResponseField>

`401` Missing or invalid API key.

<ResponseField name="code" field-type="string" required={true}>
  A machine-readable error code.
</ResponseField>

<ResponseField name="message" field-type="string" required={true}>
  A human-readable description of the error.
</ResponseField>

<ResponseField name="status" field-type="integer" required={true}>
  The HTTP status code.
</ResponseField>

## Cancel an order

> Cancels an order by ID. Only orders with a status of `pending` can be cancelled — orders that have already shipped cannot be reversed.

**DELETE** `/store/orders/{orderId}`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true}>
  Pass your API key as a Bearer token in the `Authorization` header.
</ParamField>

<ParamField path="orderId" param-type="integer" required={true}>
  The ID of the order to cancel.
</ParamField>

**Responses**

`204` Order cancelled successfully.

`401` Missing or invalid API key.

<ResponseField name="code" field-type="string" required={true}>
  A machine-readable error code.
</ResponseField>

<ResponseField name="message" field-type="string" required={true}>
  A human-readable description of the error.
</ResponseField>

<ResponseField name="status" field-type="integer" required={true}>
  The HTTP status code.
</ResponseField>

`404` The requested resource could not be found.

<ResponseField name="code" field-type="string" required={true}>
  A machine-readable error code.
</ResponseField>

<ResponseField name="message" field-type="string" required={true}>
  A human-readable description of the error.
</ResponseField>

<ResponseField name="status" field-type="integer" required={true}>
  The HTTP status code.
</ResponseField>

`409` Order cannot be cancelled — it has already shipped.
